数据说明

数据是怎么来的

  • 客户端(ccusage report)只读取本机的 AI 编程 agent 日志(JSONL),在本地聚合成「小时 × 工具 × 模型」的 token 计数后上报;不统计、不上传任何代码或对话内容。
  • 同一设备以最近一次上报为准(Latest-wins):重新执行 ccusage report 即修正当日数据。
  • 每人最多绑定 3 台设备,多设备用量自动累加;按客户端本地时区的自然日汇总。

成本估算

  • 成本为服务端按公开价格表折算的估算值,不是账单;价格表见这里。
  • 未知模型按模型家族兜底估算,并在价格表中标注 estimated。

上榜规则

  • 按 token 数量排名,按天汇总;支持按工具 / 模型 / 城市 / 时间范围 / 缓存口径筛选。
  • 缓存口径「含缓存」计入全部四类 token,「仅新增」只计输入 + 输出。
  • 单设备单日用量超过阈值会被标记(Anomaly Flag),当日不进入排行榜,数据保留且本人可见。
  • 禁止伪造上报刷榜;异常设备将被移出榜单。

如何参与

  1. 注册并在设置页生成 report token。
  2. 配置 ccusage report --server <地址> --token <token>,或写入 ccusage.json(reportServer / reportToken)。
  3. 手动执行或 ccusage report --install-timer 安装每小时自动上报。
